## 1. 공공데이터포털 키 (필수, 15분)
1. https://www.data.go.kr 가입·로그인(PC)
2. 각 페이지에서 **[활용신청]** → 목적 "해커톤 프로토타입 개발"
   - LH 분양임대공고문: https://www.data.go.kr/data/15058530/openapi.do
   - 잡알리오 채용정보: https://www.data.go.kr/data/15125273/openapi.do
   - 공공서비스(혜택) 정보: https://www.data.go.kr/data/15113968/openapi.do
   - 국가자격 시험일정: https://www.data.go.kr/data/15074408/openapi.do
   - 검색해서 신청: "마이홈포털 공공주택 모집공고"
3. 마이페이지 → 데이터활용 → Open API → 개발계정 → **일반 인증키(Decoding)** 복사
4. CSV에서 `DATA_GO_KR_KEY` 행 **하나**의 `API_KEY` 칸에 붙여넣기(키 하나로 공용)
5. 승인 대기인 API는 비고 칸에 "대기"
