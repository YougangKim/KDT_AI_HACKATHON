## 2. 이번에 적용한 것 (로컬, 커밋 안 함)

1. **국비훈련 주소**: API의 훈련기관 주소를 그대로 장소로 저장 → 다음 수집부터 1,000건 지도 표시 가능(카카오 좌표 조회는 수집당 150건씩, 90일 캐시).
2. **자격조건 파싱 보강**(`web/lib/ai/rules.ts`)
   - 부정·예외 문구: "재학생은/을 제외", "무주택 여부 무관", "신혼부부가 아닌 자", "대학원 재학생은 제외"는 조건으로 만들지 않음. 한 곳이라도 대상으로 나오면 인정. 조건 정의 안의 부정("주택을 소유하지 않은")은 인정.
   - 그동안 AI 해석에 맡기던 조건을 원문 단어로: 신혼부부·예비신혼·혼인 N년 이내, 청약통장, 경력 N년 이상(바로 앞 "신입 및"이면 동시 모집으로 제외, "경력자 우대" 제외), 학력(고졸 1·전문대 2·대졸 3·석사 4·박사 5, "학력 무관" 제외). 모두 확신도 low(탈락 대신 "확인 필요").
   - 분야 제한(`web/lib/sources/util.ts` fitsDomain): 신혼·청약통장은 주거에만, 경력·학력은 채용·알바·훈련에만 붙임. 다른 분야 공고가 불필요하게 "확인 필요"가 되지 않게.
3. 테스트 `web/lib/ai/rules-parse.test.ts` 15개. 전체 test 272·tsc·빌드 통과.
