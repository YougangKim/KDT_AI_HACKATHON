동작 규칙(구현 시)
  • 띄우는 시점: 알림 저장이 서버까지 성공했을 때만(실패 시 안 띄움). 테스트 알림 발송 직후 0.8초 뒤.
  • "다음에 할게요": 이 기기에서 7일간 다시 묻지 않음. 제출하면 다시 묻지 않음. ✕로 닫으면 "다음에"와 같게 처리.
  • 필수는 1·2·4번만, 3·5번은 선택. 제출 시 함께 저장: 현재 화면 경로, 유입 ref, 시각. IP·기기 정보는 저장 안 함.
  • 저장 위치는 기존 Upstash(앱 안 설문) 추천. 외부 폼(Tally)은 화면이 앱과 달라져서 이 디자인과 맞지 않음.
