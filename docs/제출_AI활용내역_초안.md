# AI 활용내역 (초안, 3,000자 이내) — 2026-11-21 Claude 작성

① 활용 AI 모델·도구
[서비스] Anthropic Claude API — claude-sonnet-5-5(공고 원문의 자격요건 문장을 나이·지역·무주택·소득·취업상태 조건으로 구조화), claude-haiku-5-5(질문 문장 다듬기, 매칭 이유 설명). API 키가 없거나 호출이 실패하면 규칙 기반 처리로 자동 전환.
[개발] Claude Code(Claude, 화면·서버·데이터 어댑터·테스트 코드 작성과 통합), OpenAI Codex(GPT, 필터 병목 분석 알고리즘 초안, 코드·보안 리뷰, 아이디어·시장조사 교차 평가), ChatGPT 심층 리서치(청년 주거·교통·구직·알바 고민 조사), Exa·웹 검색(경쟁 서비스·통계 원문 확인).

② AI 활용 범위와 팀의 기여
- 문제 정의: 팀이 직접 겪은 불편("조건 맞는 공고가 언제 올라오고 내려갈지 몰라 여러 사이트를 매번 확인")을 인터뷰로 정리하고, 후보 아이디어 9개를 다른 AI가 냉정하게 채점하도록 교차 평가 규칙을 만들어 선정했다. 최종 방향(게임식 조건 입력 + 분야 횡단 반복 조사·알림)은 팀이 결정했다.
- 설계: 서비스 구조, 데이터 모델, 판정은 코드·해석은 AI로 나누는 원칙, 개인정보 최소화(예·아니오 범주값만 저장)는 팀이 설계했다.
- 구현: 코드 초안은 AI가 작성했고, 팀은 병렬 작업 계약(파일 경계·인터페이스)을 정해 통합하고 테스트로 검증했다. 필터 병목 알고리즘은 Codex 초안을 Claude가 검토·수정했고, 서버 코드는 Claude가 작성한 뒤 Codex가 보안 리뷰해 8건 중 7건을 고쳤다(소유자 토큰 인증, 푸시 구독 검증, 예약 실행 비밀값 등).
- 서비스 안의 AI: 공고마다 다른 자격요건 문장을 조건으로 바꾸는 일은 규칙만으로 어려워 AI를 썼다. 사용자 답변과의 판정, 필터 병목 계산, 새 공고 비교는 코드가 수행한다.

③ API·외부 데이터·오픈소스
공공데이터포털 LH 분양임대공고문·마이홈 공공주택 모집공고(주거), 잡알리오 공공기관 채용정보(채용), 행정안전부 공공서비스(혜택) 정보·온통청년(정책·지원금), 고용24 훈련과정·Q-Net 국가자격 시험일정(교육·자격). 키가 없는 출처는 실제 공개 공고를 바탕으로 만든 예시 데이터로 대체하고 화면에 "샘플 데이터"로 표시한다. 선택 기능으로 Tavily·Exa 웹 검색(기본 꺼짐, 공공기관 도메인 한정, 제목·링크·요약 200자만 사용). 오픈소스: Next.js, React, Tailwind CSS, web-push, Vitest. 상세 출처·라이선스는 소개서 별첨 「활용한 외부 자원·출처」 표에 기재.

④ 검증 및 한계 대응
- 자동 테스트 66개(질문 엔진, 데이터 어댑터, 필터 병목, 알림 판정, 보안 유틸, 게임→결과→저장→반복 조사 통합 흐름)와 빌드·타입·린트 검사를 통과했다.
- AI가 해석한 조건에는 결과 화면에 "AI 해석" 배지와 원문 문장을 함께 보여 주고, 신뢰도가 낮거나 사용자가 "모름"으로 답한 조건은 합격으로 단정하지 않고 "확인 필요"로 남긴다. 최종 자격은 공고 원문에서 확인하도록 안내한다.
- 실제 개인정보는 외부 AI에 보내지 않는다. AI에는 공고 원문만 보내고, 사용자 답변은 예·아니오 범주값으로만 저장하며 알림함에서 삭제할 수 있다.
- 연결이 안 된 출처는 "예시 데이터"로 구분해 0건과 조사 실패를 혼동하지 않게 했다.
- 남은 한계: 현재 반복 조사는 처음 보는 공고 ID만 감지하며, 마감일 변경 감지와 서버 측 마감 임박 푸시는 아직 없다.
