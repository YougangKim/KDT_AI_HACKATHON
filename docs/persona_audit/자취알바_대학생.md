## B. 브라우저 검수 체크리스트

### 검수 원칙

- 최초 점수는 0점으로 두고 확인된 근거가 있을 때만 통과 처리한다.
- 화면에 보이지 않거나 원문에서 확인되지 않은 자격은 추정으로 가점하지 않는다.
- 공고가 없는 것과 앱이 공고를 잘못 제거한 것을 분리한다.
- 거리의 기준점은 “현재 원룸”으로 고정한다.
- 알림 권한 요청은 실제 구독 동작이므로 검수자의 허가가 있을 때만 누른다.

### 거리 대조 방법

1. 결과 카드의 공고명·표시 주소·`내 위치에서 N.Nkm`를 기록한다.
2. 지도에서 `나` 핀이 종암동 원룸 기준점인지 확인한다.
3. 공고 핀의 팝업 주소와 카드의 장소를 대조한다.
4. 지도 측정 도구 또는 별도 지도에서 기준점과 공고 좌표의 직선거리를 측정한다.
5. 앱은 직선거리이므로 실제 대중교통 거리와 직접 비교하지 않는다.
6. 차이가 0.5km 이상이면 좌표 정밀도(`정확한 주소`, `기관·단지 위치 추정`, `시·도 단위`)를 확인한다.
7. `region` 정밀도 공고는 거리 대신 “거리 판단 불가”가 표시되어야 한다.
