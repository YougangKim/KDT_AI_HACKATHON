# 페르소나 검수: 지방에서 서울로 상경하는 대학생

상태: **준비 완료, 검수 대기** (코디네이터가 시작을 알리면 http://localhost:5300 에서 진행)
결과 전달: 수정 스레드(cmsg_011U2bHPkJVqZ5yBXMvuBeQW1ZzpRMfjU1SqpLQHWYGXCH). 코드 수정·서버 종료·푸시 금지.

## 1. 인물 설정

**박서윤**, 만 21세(2005년생), 여성, 대학교 3학년 올라가는 휴학 없는 재학생.

- **출신·현재 위치**: 전북 전주시 덕진구 송천동 부모님 집. 검수 시작 시점의 기기 위치는 전주(GPS 기준 전주).
- **서울 목표 위치**: 학교가 있는 서울 동대문구 회기동(경희대 서울캠퍼스 인근, 1호선 회기역). 2학기부터 기숙사 추첨에서 떨어져 내년 3월 학기 전에 자취방을 구해야 함.
- **학교·전공**: 서울 소재 4년제 사립대, 경영학과. 1·2학년은 기숙사에 살았음.
- **가족**: 부모(아버지 자영업 식당, 어머니 파트타임), 고등학생 동생 1명. 4인 가구.
- **월수입**: 학기 중 카페 알바 주 12시간, 월 약 55만 원. 방학 중엔 월 80만 원까지.
- **부모 지원**: 월 40만 원(생활비). 등록금은 국가장학금 + 부모 부담.
- **소득분위**: 한국장학재단 학자금 지원구간 5구간(가구 월소득 인정액이 기준중위소득 약 90~100% 사이). 본인은 "중위소득 몇 %"를 정확히 모르고, 국가장학금 신청 화면에서 본 "5구간"만 기억함.
- **주거 예산**: 보증금 500만 원 이하(부모가 마련 가능한 최대), 월세+관리비 45만 원 이하. 가능하면 청년 매입임대·행복주택·전세임대 같은 공공임대를 원함. 무주택, 본인 명의 주택 없음, 청약통장은 고1 때 부모가 만든 주택청약종합저축(월 2만 원 납입).
- **통학 한도**: 회기역까지 대중교통 편도 **40분 이내**(최대 50분까지는 참음). 교통비는 월 7만 원 이내(K-패스·기후동행카드 고려). 자전거·도보 15분이면 가장 좋음.
- **관심 분야(우선순위)**: ① 주거(청년 공공임대, 월세 지원) ② 지원금(청년월세 특별지원, 장학금) ③ 알바·일경험(학교 근처, 방학 일경험) ④ 자격증(컴활 1급, 토익은 자격증 아님을 모름)
- **지식 수준**: 사회 초년생. "기준중위소득", "무주택세대구성원", "전세임대"의 정확한 뜻을 모르고, 공고문 PDF는 첫 장만 읽음. LH·SH 차이를 모름. 주소 검색은 "회기동" 또는 "경희대"로 입력할 것.
- **사용 습관**: 휴대폰(세로 화면) 위주, 질문은 빨리 넘기려 하고 모르면 "잘 모르겠어요"를 누름. 결과에 지도가 나오면 학교 주변 핀부터 누름.

### 이 인물이 앱에 기대하는 것 (해피 패스)
1. 전주에 있지만 **서울 회기동 기준**으로 공고를 보고 싶다.
2. "내 보증금·월세로 들어갈 수 있는 학교 근처 공공임대"와 "청년월세 지원"이 맨 위에 나오길 원한다.
3. 소득 질문에서 "5구간"밖에 모르는 상태로도 막히지 않고 답할 수 있어야 한다.
4. 새 공고(특히 SH·LH 청년 매입임대)가 뜨면 알림으로 받고 싶다.

## 3. 검수 체크리스트

심각도: **치명**(진행 불가·잘못된 결정 유도) / **높음**(핵심 가치 훼손) / **중간**(혼란·우회 가능) / **낮음**(문구·미관).
맞는 공고가 실제로 없는 경우는 **데이터 없음**으로 따로 적고 수정 항목에서 뺀다. 감점에서 출발한다.

### A. 첫 진입·관심 분야
- [ ] 홈에서 무엇을 하는 앱인지 10초 안에 이해되는가(사회 초년생 기준)
- [ ] 주거·지원금·알바·자격증 복수 선택이 되고, 선택 상태가 분명히 보이는가
- [ ] 세로 모바일(375px)에서 버튼이 잘리지 않는가

### B. 위치 설정 (중점)
- [ ] 현재 위치(전주) 자동 감지와 "다른 곳 기준으로 보기"가 분리돼 있는가
- [ ] "회기동", "경희대", "회기역" 주소 검색이 결과를 내는가, 결과 목록이 보이는가
- [ ] 지도에서 회기동을 직접 찍을 수 있는가
- [ ] 전주 위치를 거부(권한 차단)했을 때 안내 문구와 우회 경로
- [ ] 탐색 위치(서울)와 알림 위치가 각각 무엇인지 설명되는가, 서로 덮어쓰지 않는가
- [ ] 결과 화면의 거리 계산 기준점이 전주가 아니라 회기동인가(가장 중요)
- [ ] 거리 반경 조절이 통학 40~50분 감각과 연결되는가(km만 있으면 감점)
- [ ] 위치를 바꾼 뒤 결과가 다시 계산되는가, 지난 결과가 남아 섞이지 않는가
- [ ] "위치 지우기" 후 상태가 깨끗이 초기화되는가

### C. 질문 흐름
- [ ] 소득 질문을 "5구간"만 아는 사람이 답할 수 있는가(설명·예시·모름 선택지)
- [ ] 같은 내용(소득·나이)을 반복해서 묻지 않는가
- [ ] 거주 지역 질문이 "현재"인지 "이사 갈 곳"인지 명확한가
- [ ] 질문별 버튼 문구가 뜻을 정확히 전달하는가("예면 N개·아니오면 M개" 숫자 일관성)
- [ ] "바로 결과 보기"로 중간에 끊어도 결과가 합리적인가

### D. 결과·리스트
- [ ] 상위 3개가 페르소나 우선순위(주거·월세 지원)와 맞는가
- [ ] 전북 전용 공고(전주시 청년 정책)가 서울 탐색 기준에서 잘못 상위에 오는가
- [ ] 서울 거주 요건 공고에서 "아직 전입 전" 상태가 확인 필요로 표시되는가
- [ ] 보증금·월세 정보가 카드에 보이는가, 예산 초과 공고를 구분할 수 있는가
- [ ] 각 카드의 이동 거리·소요 시간 표기를 실제 지도 거리와 대조(최소 5건)
- [ ] 적합성 근거(통과·확인 필요·탈락)가 질문 답과 일치하는가(최소 5건)
- [ ] "더보기"와 마감 지난 공고 처리

### E. 지도 핀 ↔ 리스트 연동
- [ ] 핀 클릭 → 리스트 해당 카드 강조·스크롤
- [ ] 리스트 카드 클릭 → 지도 해당 핀 강조·이동
- [ ] 분야별 핀 색이 구분되고 범례가 있는가
- [ ] 회기동 기준점 표시가 지도에 있는가, 전주가 기준점으로 남지 않는가
- [ ] 같은 단지 다중 공고·위치 추정 핀("기관·단지 위치 추정") 표기

### F. 탭
- [ ] 전체·분야별 탭 건수 표기와 실제 목록 수 일치
- [ ] 전체 탭에서 고른 분야가 번갈아 보이는가(한 분야 독차지 여부)
- [ ] 탭 전환 시 지도 핀도 같이 걸러지는가

### G. 분석 화면 (/result/analysis)
- [ ] 통과율·병목 조건이 사회 초년생에게 이해되는 말로 나오는가
- [ ] 병목 완화 제안이 이 인물에게 실현 가능한가(예: "서울 전입" 제안의 타당성)
- [ ] 분석 숫자와 결과 리스트 숫자가 맞는가

### H. 추가 질문으로 좁히기
- [ ] "질문 더 해서 좁히기"가 지난 답을 이어받는가(반복 질문 없음)
- [ ] 좁힌 뒤 결과 수 변화가 예측("예면 N개")과 맞는가
- [ ] 위치 설정(회기동)이 좁히기 후에도 유지되는가

### I. 알림 설정
- [ ] 알림 저장 동의 문구가 이해되는가, 서버에 무엇이 저장되는지(약 1km 위치)
- [ ] 알림 위치가 탐색 위치(회기동)로 저장되는가
- [ ] 브라우저 알림 권한 거부 시 안내
- [ ] 알림함에서 실데이터/예시 구분, 조건 지우기 동작

### J. 공통
- [ ] 콘솔 오류, 로딩 무한 대기, 빈 화면
- [ ] 뒤로 가기·새로고침 시 상태 유지
- [ ] 원문 링크가 실제 공고로 가는가(최소 3건)
