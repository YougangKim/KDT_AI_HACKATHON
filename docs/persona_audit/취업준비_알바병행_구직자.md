# My News 페르소나 검수 준비서 — 취업·알바 병행 구직자

## 1. 검수 목적

사회 초년생이 My News에서 취업·알바·청년지원 공고를 자신의 조건에 맞게 찾고, 결과의 근거를 이해하며, 알림까지 설정할 수 있는지 검수한다.

- 대상 경로: `/` → `/play` → `/result` → `/result/analysis` → `/alerts` → `/settings`
- 판정 원칙: 공고가 없는 것과 앱이 잘못 거른 것을 구분한다.
- 주의: 공고 제목만 보지 말고 원문 자격조건을 대조한다.

## 2. 페르소나

### 김서윤, “취업 준비도 해야 하고 당장 월세도 벌어야 하는 사람”

김서윤은 만 25세로 서울특별시 관악구 신림동에 산다. 부천에서 부모님과 살다가 면접과 학원 이동 시간을 줄이려고 독립했다. 2025년 2월 수도권 4년제 대학에서 미디어커뮤니케이션을 전공했으며, 자격증과 정부지원 제도에 익숙하지 않은 사회 초년생이다.

현재 카페와 행사 스태프 알바를 병행해 월평균 세전 165만 원을 번다. 2026년 1인 가구 기준중위소득은 월 2,564,238원이며, 서윤의 소득 비율은 약 **64.3%**이다. My News 소득 선택지에서는 **61~80% 구간**에 해당한다. 이는 앱 검수용 소득 구간이며 통계상의 소득 10분위를 뜻하지 않는다. 기준값은 [보건복지부 기준 중위소득 안내](https://www.mohw.go.kr/menu.es?mid=a10708010900)를 따른다.

- 주소: 서울특별시 관악구 신림동
- 가구: 1인 가구, 미혼, 부양가족 없음
- 주거: 보증금 1,000만 원, 월세 52만 원, 관리비 별도 7만 원
- 이동 한도: 편도 45분, 왕복 90분
- 교통비 한도: 하루 5,000원, 월 10만 원 안팎
- 희망 직무:
  - 1순위 NCS `경영·회계·사무`
  - 2순위 NCS `문화·예술·디자인·방송`
  - 보조 관심 NCS `정보통신`
- 취업 조건: 서울 근무, 신입·인턴·계약직 허용, 주 5일 사무직 선호
- 알바 조건: 시급 12,000원 이상, 화·목·토, 평일 18:00~23:00 또는 토요일 10:00~18:00, 집에서 5km 이내
- 관심 지원:
  - 국민내일배움카드·취업훈련
  - 청년수당·구직활동지원금
  - 청년 월세·공공임대
  - 취업 관련 자격증 일정
- 앱에 기대하는 것:
  - 나이·소득·거리 때문에 신청할 수 없는 공고를 먼저 걸러 주기
  - 취업과 알바 결과를 한 화면에서 비교하기
  - 탈락하거나 “확인 필요”인 이유를 쉬운 말로 설명하기
  - 새 공고와 마감 임박 공고를 놓치지 않게 알려 주기
- 말투:
  - “제가 진짜 신청할 수 있는 거 맞아요?”
  - “중위소득 80%가 월급으로 얼마예요?”
  - “알바 끝나고 갈 수 있는 시간인지 바로 보고 싶어요.”
  - “확인 필요라고만 하지 말고 뭘 확인해야 하는지 알려 주세요.”

## 3. 사전 조건

- 로컬 URL: `http://localhost:5300`
- 브라우저 위치 권한 상태를 기록한다.
- 이전 `sessionStorage`, 알림 조건 및 알림 기록을 비운 상태에서 시작한다.
- 같은 공고를 지도와 목록에서 식별할 수 있도록 제목과 기관명을 기록한다.
- 데이터가 매번 달라질 수 있으므로 건수 자체보다 필터와 상호작용의 일관성을 우선한다.

## 4. 단계별 검수 체크리스트

### 01. 관심 분야 선택

**조작**

홈에서 `채용·인턴`, `알바·단기직`, `국비 과정`, `지원금·혜택`, `청년 주택`, `자격증 일정`을 선택한다. 0건으로 비활성화된 분야가 있으면 별도로 기록하고, 선택 가능한 관심 분야로 시작한다.

- 기대 결과: 선택 상태와 분야별 공고 건수가 보이며 선택한 분야 수가 시작 버튼에 반영된다.
- 통과 기준: 선택 가능한 모든 분야가 `/play?domains=...`에 전달되고, 0건 분야는 선택 전에 “연결 준비 중”으로 구분된다.
- 확인할 조건 불일치: 관심 분야 밖 공고가 결과에 섞이는지, 선택 가능하다고 표시한 분야가 실제로 0건인지 확인한다.
- 스크린샷: `docs/persona_audit/shots/jobseeker_01_domain_selection.png`

### 02. 위치·반경 설정

**조작**

주소 검색에 `서울 관악구 신림동`을 입력한다. 검색된 위치를 확인한 뒤 `5km`를 선택하고 `이 위치로 계속하기`를 누른다. GPS 거부 시에도 주소 검색과 지도 직접 선택이 가능한지 확인한다.

- 기대 결과: 검색 위치, “나” 핀 및 5km 원이 지도에 표시되고 해당 위치가 결과 필터에 저장된다.
- 통과 기준: 1·2·5·10km와 `상관없어요`가 구분되며 5km 선택 후 다음 단계로 이동한다.
- 확인할 조건 불일치: 5km 밖 공고가 포함되거나 주소가 다른 동·구로 잡히는지 확인한다.
- 스크린샷: `docs/persona_audit/shots/jobseeker_02_location_radius.png`

### 03. 질문 응답

질문 순서는 데이터에 따라 달라질 수 있다. 아래 항목이 나타나면 다음과 같이 답한다.

| 질문 | 예상 답 |
|---|---|
| 만 나이 | 25세가 포함된 구간 |
| 사는 지역 | 서울 |
| 소득 구간 | 61~80% |
| 취업 상태 | `구직 중`, 별도 선택이 가능하면 `알바·단기 근로`도 검토 |
| 최종 학력 | 대졸(4년제) |
| 직무 분야 | `경영·회계·사무`, `디자인·문화예술`, `정보통신(IT·소프트웨어)` |
| 필요한 지원 | 취업훈련·구직지원·주거비 성격의 항목 |
| 주거 형태 | 임대(월세·전세) |
| 관심 분야 | 채용·인턴, 알바·단기직, 국비 과정, 지원금·혜택, 청년 주택, 자격증 일정 |
| 이해하기 어려운 조건 | 추측하지 않고 `잘 모르겠어요` |

- 기대 결과: 선택한 답이 즉시 반영되고 남은 공고 수가 갱신되며, 같은 나이·소득 질문이 반복되지 않는다.
- 통과 기준: 최소 2문항 이후 결과 보기가 가능하고, 복수 선택 질문에서 선택값이 명확하며, 응답 이력이 결과에 보존된다.
- 확인할 조건 불일치: 만 25세 제외, 80% 이하 대상에서 잘못 탈락, 대졸 제한 오판, 구직자와 알바 근로 상태의 충돌을 확인한다.
- 스크린샷: `docs/persona_audit/shots/jobseeker_03_question_answers.png`

### 04. 결과 목록과 조건 판정

**조작**

결과로 이동해 전체 건수, 바로 신청 건수, 확인 필요 표시, 반경 밖 제외 건수, 처음 노출된 3개 공고를 확인한다. `더보기`가 있으면 연다.

- 기대 결과: 적합도가 높은 공고가 먼저 보이고, 각 카드에 분야·기관·마감일·장소·신청 방법·거리·확인 필요 조건이 표시된다.
- 통과 기준: 카드의 원문 링크가 실제 공고로 연결되고, “바로 신청”과 “확인 필요”가 근거 없이 뒤바뀌지 않는다.
- 확인할 조건 불일치:
  - 나이: 만 25세가 상한을 초과하는 공고
  - 소득: 기준중위소득 64.3%가 허용 범위를 초과하는 공고
  - 거리: 신림동 기준 5km 초과 공고
  - 시간대: 평일 주간 알바나 화·목·토 조건과 명백히 충돌하는 알바
- 스크린샷: `docs/persona_audit/shots/jobseeker_04_result_list.png`

### 05. 지도 핀 → 목록 추적

**조작**

결과 지도에서 제목을 식별할 수 있는 핀 하나를 선택한다.

- 기대 결과: 대응하는 목록 카드로 자동 스크롤되고 해당 카드가 약 2.5초간 강조된다.
- 통과 기준: 핀의 공고 ID와 강조된 카드의 제목·기관이 정확히 일치한다.
- 확인할 조건 불일치: 현재 분야 탭에 없는 핀이 보이는지, 반경 밖 공고나 다른 지역 공고로 이동하는지 확인한다.
- 스크린샷: `docs/persona_audit/shots/jobseeker_05_map_to_list.png`

### 06. 목록 → 지도 핀 추적

**조작**

정확·근사 위치가 있는 카드의 `지도에서 보기`를 누른다.

- 기대 결과: 지도 화면이 해당 핀으로 이동하고 팝업이 열린다.
- 통과 기준: 카드와 핀의 제목·기관·분야가 일치하며 지도 범례의 핀 색도 해당 분야와 일치한다.
- 확인할 조건 불일치: 다른 핀이 열리거나 시·도 단위 위치를 정확한 주소처럼 표시하는지 확인한다.
- 스크린샷: `docs/persona_audit/shots/jobseeker_06_list_to_map.png`

### 07. 분야별 탭

**조작**

`전체`, `채용`, `알바·단기`, `지원금`, `국비 과정`, `주거`, `자격증` 중 표시되는 탭을 차례로 선택한다.

- 기대 결과: 선택 분야의 카드와 지도 핀만 남고 탭별 건수가 목록 건수와 일치한다. 전체 탭에서는 분야가 번갈아 노출된다.
- 통과 기준: 탭 전환 시 URL의 `tab` 값, 카드 `data-domain`, 지도 핀 및 표시 건수가 모두 일치한다.
- 확인할 조건 불일치: 채용 탭에 알바가 섞이거나 알바 탭에서 시간대·거리 불일치가 숨겨지는지 확인한다.
- 스크린샷: `docs/persona_audit/shots/jobseeker_07_domain_tabs.png`

### 08. 분석 화면 이해도

**조작**

`분석 보기`로 이동해 전체→통과 과정, 조건별 탈락 수, 질문별 빠진 공고, 완화 제안을 읽는다.

- 기대 결과: 사회 초년생도 “내 어떤 답 때문에 몇 건이 빠졌는지”와 “무엇을 풀면 몇 건이 늘어나는지” 설명할 수 있다.
- 통과 기준: 서윤이 도움 없이 30초 안에 가장 많이 제외시킨 조건 하나를 말하고, `바로 신청`과 `확인 필요`의 차이를 설명한다.
- 확인할 조건 불일치: 나이·소득·거리 필터의 탈락 수가 실제 결과 변화와 다른지, 시간대 조건이 없는데 적합으로 단정하는지 확인한다.
- 스크린샷: `docs/persona_audit/shots/jobseeker_08_analysis_comprehension.png`

### 09. 추가 질문으로 좁히기

**조작**

결과 또는 분석에서 `추가 질문으로 더 좁히기`를 누르고 최대 5개의 후속 질문에 답한다. 답은 기존 페르소나 조건을 유지한다.

- 기대 결과: 기존 답과 위치가 보존되고 새 질문만 제시되며, 완료 후 `기존 N개 → M개로 좁혔어요`가 표시된다.
- 통과 기준: `M ≤ N`이고 기존 답이 중복 질문으로 다시 나오지 않으며, 새 답으로 제외된 공고가 분석에 반영된다.
- 확인할 조건 불일치: 후속 질문 뒤 만 25세·64.3%·5km 조건이 사라지거나, 허용한 시간대와 맞지 않는 알바가 새로 포함되는지 확인한다.
- 스크린샷: `docs/persona_audit/shots/jobseeker_09_narrow_questions.png`

### 10. 조건 완화와 조건 고치기

**조작**

조건 완화 제안이 있으면 하나를 눌러 증가 건수를 확인한다. 이어서 `조건 고치기`를 열어 해당 답을 원래 값으로 복구한다.

- 기대 결과: 완화된 답은 `모름`으로 바뀌고 증가 건수가 `바로 신청`과 `확인 필요`로 나뉘어 안내된다.
- 통과 기준: 안내된 증가량과 실제 목록 증가량이 같고, 원래 답으로 복구하면 결과도 원상 복구된다.
- 확인할 조건 불일치: 나이·소득·거리를 완화한 공고가 `바로 신청`으로 과장되는지 확인한다.
- 스크린샷: `docs/persona_audit/shots/jobseeker_10_condition_edit.png`

### 11. 알림 저장·설정

**조작**

`이 조건으로 알림 받기`를 누른 뒤 알림 권한 결과를 기록한다. `/settings`에서 다음과 같이 설정한다.

- 관심 분야: 채용, 알바·단기, 지원금, 국비 과정, 주거, 자격증
- 알림 위치: 신림동, 5km
- 일정: `특정 시각`, 08:00과 17:50
- 방해 금지: 23:00~08:00
- 모드: `새 공고가 있을 때만`

저장 후 `/alerts`에서 조건 요약과 조사 상태를 확인한다.

- 기대 결과: 기기와 서버 저장 결과가 명확히 표시되고, 권한 거부 시에도 앱 내 알림함 이용이 가능하다.
- 통과 기준: 다시 설정 화면에 들어갔을 때 분야·위치·반경·시각·방해 금지·모드가 유지되며 알림함에서 조건 삭제가 가능하다.
- 확인할 조건 불일치: 저장된 알림이 만 25세·64.3%·5km 조건을 잃거나, 방해 금지 시간에 알림을 보내거나, 알바 시간대가 맞는 것처럼 표현하는지 확인한다.
- 스크린샷: `docs/persona_audit/shots/jobseeker_11_alert_settings.png`

## 5. 문제 기록 양식

## 6. 냉정한 감점 기준

100점에서 차감하며 최저점은 0점이다. 같은 원인의 연쇄 증상은 가장 높은 항목 한 번만 차감한다.

- **치명 −25점/건**
  - 명백한 나이·소득·거리 부적격 공고를 `바로 신청`으로 표시
  - 알림 조건이 다른 사용자 조건으로 저장됨
  - 신청 링크가 무관하거나 위험한 페이지로 연결됨
  - 주요 흐름 진행 불가 또는 저장된 조건 소실
- **높음 −12점/건**
  - 지도 핀과 목록 카드가 다른 공고를 가리킴
  - 분야 탭의 건수·목록·핀이 불일치
  - 추가 질문 후 기존 답이나 위치 조건이 사라짐
  - 조건 완화 증가량이 실제 결과와 다름
  - 권한 거부 후 알림 대체 경로를 제공하지 않음
- **중간 −5점/건**
  - `확인 필요`의 구체적인 확인 항목이 없음
  - 분석 화면에서 탈락 원인이나 건수를 이해하기 어려움
  - 근사 위치를 정확한 주소처럼 표현
  - 시간대 정보가 없는데 알바 적합성을 단정
- **낮음 −2점/건**
  - 사회 초년생이 이해하기 어려운 용어에 설명이 없음
  - 선택 상태, 거리 단위, 알림 저장 결과가 불명확
  - 경미한 정렬·강조·문구 불일치
- **데이터 없음**
  - 기능 결함으로 감점하지 않는다.
  - 단, 0건 상태 설명·조건 완화·알림 저장 경로가 없으면 해당 UX 문제는 별도로 감점한다.

### 최종 판정

- 90~100점: 통과
- 75~89점: 조건부 통과
- 60~74점: 재검수 필요
- 0~59점: 출시 차단

> Tavily 검색은 사용 한도 오류(432)로 실패하여, 2026년 기준중위소득은 보건복지부 공식 페이지를 대체 검색으로 확인했다.
