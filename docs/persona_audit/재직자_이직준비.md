## 1. 인물 설정

**한지우, 27세, 1인 가구, 회사 2년 차**

- **직장**: 서울 금천구 가산디지털단지역 근처 중소 물류회사(직원 40명). 재고관리팀 사무직, 하는 일은 ERP 입출고 입력과 엑셀 재고 보고서. 9시 출근 6시 퇴근, 야근 주 1~2회.
- **연봉**: 세전 3,000만 원(월 세전 약 250만 원, 세후 약 220만 원). 상여 없음. 본인은 "월급 220"으로만 알고 있고 세전 금액은 원천징수영수증을 찾아봐야 안다.
- **소득분위 감각**: 2026년 1인 가구 기준중위소득(월 약 256만 원)의 **약 98%**. 100% 기준 바로 아래라 "100% 이하"에 걸칠지 스스로 판단이 안 된다. "중위소득"이라는 말을 정확히 모른다. 이 경계가 검수 포인트다.
- **주거**: 경기 안양시 동안구 평촌 원룸 월세(보증금 1,000만 원, 월 50만 원+관리비 7만 원). 무주택, 부모와 세대 분리됨. 청약통장(주택청약종합저축) 가입 3년, 월 2만 원씩 넣음. 주거비가 월급의 26%라 **청년 매입임대·행복주택·청년 전세임대**에 관심. 분양은 아직 먼 얘기로 생각하지만 공고가 뜨면 보고 싶다.
- **원하는 주거 지역**: 직장 가까운 서울 서남권(금천·구로·관악·영등포) 또는 지금 사는 경기 남부(안양·군포·광명).
- **감당 가능한 출퇴근**: 편도 **최대 60분**(지금 45분, 4호선+1호선 환승). 교통비 **월 10만 원 이내**(K-패스 사용 중). 자차 없음, 대중교통만.
- **이직 목표**: 1년 안에 **데이터 분석·IT 사무직**(공공기관 전산직, 중견기업 데이터 담당)으로 이직. 일하는 지역은 서울 또는 경기 남부. 지금 회사는 다니면서 준비하므로 평일 낮 면접·교육은 어렵고, **야간·주말 과정**만 가능.
- **목표 자격증**: ① 정보처리기사(Q-Net, 내년 1회 필기) ② SQLD ③ ADsP. 컴활 1급은 "있으면 좋다"는 정도. 시험 접수 마감을 자주 놓쳐서 일정 알림을 가장 원한다.
- **국비 과정**: 재직자 내일배움카드는 있다고 들었지만 신청은 안 해 봄. 야간·주말 데이터 분석 과정이 있으면 관심.
- **지식 수준**: 사회 초년생. "기준중위소득", "무주택 세대구성원", "재직자 훈련" 같은 용어는 들어봤지만 정확히는 모름. 나이 기준(만 나이), 세전/세후, 1인 가구 여부 같은 질문에서 헷갈릴 수 있다. 앱이 이 정도 사람도 질문에 답할 수 있게 풀어 주는지 본다.
- **폰 사용 습관**: 출퇴근 지하철에서 폰으로 본다. 한 번에 5분 이상 붙잡지 않는다. 알림은 많으면 끈다(주 1회 요약 선호).

## 2. 검수 시나리오 (처음 방문부터)

1. 홈에서 관심 분야로 **자격증 일정 + 채용·인턴 + 청년 주택** 3개를 고른다(필요하면 국비 과정 추가 회차도).
2. 질문에 한지우처럼 답한다. 만 27세, 직장인(재직 중), 1인 가구, 무주택, 소득은 "잘 모르겠음"을 먼저 누르고 그다음 회차는 "100% 이하"로 답해 차이를 본다. 지역은 직장(가산)과 집(평촌) 주소 검색을 모두 시도.
3. 결과 전체 탭과 분야별 탭, 지도, 분석 화면, 추가 질문으로 좁히기, 알림 설정 순서로 본다.

## 3. 검수 체크리스트

각 항목: 통과/문제/데이터 없음. 문제는 스크린샷 + 심각도(치명·높음·중간·낮음) + 수정 제안. 맞는 공고 자체가 없으면 "데이터 없음"으로 분류하고 수정 항목에서 뺀다.

### A. 시작·질문
- [ ] 홈에서 분야 3개 동시 선택이 쉽고, 선택 상태가 눈에 보이는가
- [ ] "직장인인데 이직 준비" 상태를 답할 방법이 있는가. 재직자라서 채용·국비 공고가 통째로 탈락하지 않는가(취업 상태는 "확인 필요" 처리가 맞는지)
- [ ] 소득 질문: 세전/세후·기준중위소득을 초년생이 이해할 설명이 있는가. "잘 모르겠음"을 골라도 진행되는가. 98% 경계에서 결과가 납득되는가
- [ ] 같은 내용을 두 번 묻지 않는가(소득·나이 중복 질문)
- [ ] 질문별 버튼 문구가 질문과 맞는가, "예면 N개·아니오면 M개"가 실제 결과 수와 맞는가
- [ ] 주소 검색(가산디지털단지, 평촌)이 결과를 표시하고 고를 수 있는가
- [ ] 출퇴근 시간(60분)·교통비 조건을 넣을 곳이 있는가, 없다면 반경 개념이 무엇인지 설명되는가

### B. 결과 리스트·탭
- [ ] 전체 탭에서 세 분야가 번갈아 보이는가(한 분야가 상위 독점 안 하는가)
- [ ] 분야별 탭 이름·개수가 맞고, 탭 전환 시 리스트가 바로 바뀌는가
- [ ] 자격증 카드에 시험명·회차·접수 기간·시험일이 구분돼 보이는가(정보처리기사 일정 확인). SQLD/ADsP가 없으면 "데이터 없음"
- [ ] 채용 카드에 근무지·마감일·경력 조건이 보이고, 재직자에게 맞는지 판단 근거가 있는가
- [ ] 주택 카드에 공급 유형(매입임대·행복주택 등)·소득 기준·무주택 조건·지역이 보이는가
- [ ] 마감 지난 공고가 섞이지 않는가, D-day 표기가 맞는가
- [ ] "더보기"와 "질문 더 해서 좁히기" 동작

### C. 지도 (핵심)
- [ ] **자격증·채용·주거 핀 색이 확실히 구분되는가**. 특히 자격증(회색 계열)이 지도 배경·비활성 핀과 헷갈리지 않는가, 색약 사용자도 구분 가능한가(모양·아이콘 차이 여부)
- [ ] 범례가 있고 탭 색과 핀 색이 일치하는가
- [ ] 핀 클릭 → 리스트 해당 카드 강조·스크롤, 카드 클릭 → 지도 핀 강조·이동 (양방향)
- [ ] 같은 위치(시험장 등)에 겹친 핀 처리
- [ ] 위치 없는 공고(온라인 시험 접수 등)가 지도에서 빠진 이유가 설명되는가
- [ ] 탭을 바꾸면 지도 핀도 그 분야만 남는가

### D. 이동 거리·적합성 대조
- [ ] 리스트에 표시된 거리·이동 시간이 기준 주소(가산/평촌)에서 실제와 대략 맞는가(지도 앱 기준 표본 5건 대조)
- [ ] 60분 넘는 공고가 "적합"으로 표시되지 않는가
- [ ] 주택: 서울 서남권·경기 남부 외 지역이 상위에 오지 않는가. 지역 제한(해당 시·도 거주/근무) 판정이 직장 주소를 반영하는가
- [ ] 판정 근거(통과·확인 필요·탈락 이유)가 한지우 답변과 모순되지 않는가

### E. 분석 화면
- [ ] 통과율·조건별 탈락이 숫자로 맞는가(리스트 개수와 대조)
- [ ] 병목 조건(소득·나이·취업 상태)이 초년생이 이해할 문장인가
- [ ] 분야별 통계가 세 분야 모두 나오는가

### F. 추가 질문으로 좁히기
- [ ] 지난 답을 이어받고 새 질문만 하는가
- [ ] 좁힌 뒤 결과 수가 줄고, 줄어든 이유가 보이는가
