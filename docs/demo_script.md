## 심사 예상 질문 대비 (docs/market_research.md 7절과 함께)
- 오늘 실데이터로 조회된 출처는? → 알림함 출처 칩(실데이터/예시)로 그 자리에서 보여 준다.
- 분야마다 자격 구조가 다른데 한 프로필로 되나? → 공통 속성(나이·지역·무주택·소득·취업상태)만 묻고, 분야 특유 조건은 "확인 필요"로 남긴다.
- 오알림 책임은? → 결과는 참고용, 원문 링크·원문 자격 문장 표시, 최종 확인은 공고처.
