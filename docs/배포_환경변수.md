# Vercel 배포 환경변수 (2026-11-22 기준)

값은 이 문서에 적지 않는다. 값은 `web/.env.local`(로컬, 깃에 안 올라감)에 있고, Vercel 프로젝트 → Settings → Environment Variables에 같은 이름으로 넣는다(Production·Preview 모두 체크). 넣은 뒤 **Redeploy** 해야 반영된다.

## 필수

| 이름 | 용도 | 값 출처 |
|---|---|---|
| `DATA_GO_KR_KEY` | LH·마이홈·청약홈·잡알리오·공공서비스·Q-Net 실데이터 | `web/.env.local` |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | 조건·알림 구독 저장(Upstash). Vercel Storage 연결 시 **자동으로 들어감** | 자동 |
| `CRON_SECRET` | 매일 09:00 자동 조사(`/api/cron/scan`) 인증. 없으면 운영에서 503 | `web/.env.local` |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` | 앱을 닫아도 오는 푸시 알림 | `web/.env.local` |

## 권장

| 이름 | 용도 | 값 출처 |
|---|---|---|
| `GEMINI_API_KEY` | AI 자격요건 해석·질문 문장(무료 등급). 없으면 규칙 기반 | `web/.env.local` |
| `VAPID_SUBJECT` | 푸시 발신자 표기(`mailto:본인메일`). 없으면 데모 주소 | 직접 입력 |

## 선택

| 이름 | 용도 |
|---|---|
| `WEB_SEARCH_ENABLED=1` + `EXA_API_KEY` (`TAVILY_API_KEY`) | 웹 검색 보충. Tavily는 현재 계정 한도 초과라 Exa만으로 충분 |
| `JEV_API_KEY` | 웹 검색 결과가 실제 모집 공고인지 판별 |
| `GEMINI_MODEL` | 기본 `gemini-3.5-flash-lite`. 바꿀 때만 |
| `SH_RSS_ENABLED=1` | SH 공식 RSS(이용약관 확인 후) |
| `SARAMIN_ENABLED=1` + `SARAMIN_KEY` | 사람인(승인 후) |

## 넣지 않는 것
- `ANTHROPIC_API_KEY`: 유료라 쓰지 않음(넣으면 Gemini보다 우선 사용)
- `WORK24_TRAINING_KEY`: 기업회원 전용이라 발급 불가 → 국비 과정은 예시 데이터

## 배포 후 확인 순서
1. 홈 → 분야 선택 → 질문 → 결과에 실공고(“예시” 배지 없음) 표시
2. "이 조건으로 알림 받기" → 알림 허용 → 알림함에서 "지금 다시 조사하기"
3. 알림함 상단이 "데모 모드"가 아니라 "매일 오전 9시 자동 조사"로 표시되는지(Upstash 연결 확인)
