# 프로젝트 소개서 초안 (양식 슬라이드 순서대로) — 2026-11-21 Claude

> 양식: `해커톤 지침/(첨부2)` 12쪽. 본문 10장 이내. 수치는 `docs/market_research.md`에서 원문 확인된 것만 사용("국내 최초" 등 금지). [사용자 입력]은 직접 채울 것. 구현 안 된 기능(마감 변화 감지·서버 D-3 푸시·주 3건 상한)은 쓰지 않는다.

## 표지
- 프로젝트명: **마이뉴스**
- 슬로건: 질문 몇 개로 조건을 정하면, 청년 주택·채용·지원금 공고를 매일 대신 찾아 처음 보는 것만 알려 주는 AI 에이전트
- 팀명·대표자·팀원·제출일: [사용자 입력]

## 프로젝트 요약
- 한 줄 요약: 예·아니오 게임으로 조건을 정하면, 여러 공공 출처를 매일 다시 조회해 조건에 맞는 새 공고만 알려 주고, 어떤 조건이 결과를 줄이는지까지 보여 주는 청년 기회 리서치 에이전트
- 문제: 조건 맞는 공고가 언제 올라오고 내려갈지 몰라 LH·마이홈·잡알리오·정부24 등을 따로따로, 매번 직접 확인해야 한다
- 해결 방안: ① 게임식 조건 입력(6문항 안쪽) ② 분야를 가로지르는 반복 조사 + 새 공고 알림 ③ 필터 병목 분석과 완화 제안
- 구현 현황: 배포 링크에서 게임→결과→알림 저장→반복 조사→주간 리포트 동작. 자동 테스트 66개 통과 [배포 후 링크·실데이터 출처 수 갱신]
- 키워드: 청년, 공공데이터, 반복 리서치, 알림, 조건 필터링, AI 자격요건 해석

## 01 문제 정의
- 장면: 경기 북부에 사는 취업 준비 청년이 임대주택·공공기관 인턴·지원금 공고를 각기 다른 사이트에서 날마다 확인한다. 놓친 공고는 마감 뒤에야 안다.
- 근거(원문 확인): 2024 청년 삶 실태조사(만 19~34세 15,098명) — 필요한 정책 분야 주거 45.7%, 일자리 33.5% / 공공임대 거주 의향 71.7%, 경험 7.0% / 취업 정보 경로 중 공공기관은 24.4%. ※ 격차의 원인이 공고 누락이라고 단정하지 않는다.
- 기존 서비스는 분야별로 나뉘어 있다: 혜택(정부24 혜택알리미·카카오뱅크), 주거(LH·마이홈 알림), 채용(잡코리아·사람인·잡알리오). 한 조건으로 여러 분야를 함께 지켜보는 기능은 조사 범위에서 확인하지 못했다(존재하지 않는다는 뜻은 아님).

## 02 대상 사용자
- 주요 사용자: 만 19~34세 독립·독립 준비 청년, 특히 주거와 일자리를 동시에 찾는 취업 준비생
- 보조: 청년센터·대학 취업지원 담당자(상담 전 조건 정리 도구)
- 얻는 가치: 여러 사이트 반복 확인 시간 절감, 조건에 안 맞는 공고 걸러내기, "왜 결과가 적은지"를 알고 조건을 고칠 수 있음

## 03 AI를 활용한 해결 방안
- 개요: 공고 원문 수집 → AI가 자격요건 문장을 조건으로 구조화 → 게임으로 받은 답과 코드로 판정 → 새 공고만 알림
- 왜 AI인가: 공고마다 자격요건 문장 형식이 달라("만 19세 이상 39세 이하 무주택 세대구성원…") 규칙만으로는 조건을 뽑기 어렵다
- AI 적용 지점: ① 자격요건 → 조건 구조화(신뢰도 표시) ② 질문 문장 다듬기 ③ 매칭 이유 설명. 판정·병목 계산·새 공고 비교는 코드
- 오류·불확실성 대응: AI 해석 조건에 "AI 해석" 배지와 원문 문장, 저신뢰·"모름" 조건은 "확인 필요", AI 실패 시 규칙 기반 자동 전환

## 04 서비스 구조
- 구조도(그릴 것): 브라우저(PWA·서비스워커) ↔ Next.js 서버(질문 엔진, 퍼널 분석, /api/opportunities, /api/watch) ↔ 출처 어댑터(LH·마이홈·잡알리오·공공서비스·온통청년·고용24·Q-Net, 실패 시 샘플) ↔ Claude API / Upstash(조건·구독) / Vercel Cron(매일 09:00) → Web Push
- 기술 스택: Next.js 15·React 19·Tailwind / Next.js API Routes·Vercel Cron / Claude sonnet·haiku / 공공데이터포털·고용24 Open API / 공공누리 표시 확인 [배포 후] / Vercel

## 05 핵심 기능 및 사용자 흐름
- 기능 1 게임식 조건 입력: 예·아니오·모름, "예면 N개·아니오면 M개 남아요", 2문항부터 바로 결과
- 기능 2 필터 병목 분석: 전체 중 통과 %, 조건별 탈락 막대, "이 조건을 풀면 +N건"·"꼭 지켜야 해요"
- 기능 3 반복 조사·알림: 조건 저장 → 매일 재조회 → 처음 보는 공고만 푸시, 조사 기록·주간 리포트, 출처별 실데이터/예시 표시
- Happy Path: 홈 → 질문 4~6개 → 결과(요약 문장·퍼널·카드) → 알림 저장 → 다음 날 새 공고 푸시 → 알림함 리포트

## 06 차별점
- 분야 횡단: 한 번 만든 조건을 주거·채용·지원금·국비과정·자격증에 공통 적용
- 가벼운 입력: 긴 폼 대신 갈리는 질문만
- 설명 가능한 필터링: 결과가 적은 이유(병목 조건)와 완화 효과를 숫자로
- 정직한 출처 표시: 실데이터/예시/웹 검색 결과 구분, 0건과 조사 실패 구분
