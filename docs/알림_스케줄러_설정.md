# 알림 스케줄러 설정

## cron-job.org에서 1분 간격 호출

1. [cron-job.org](https://cron-job.org)에 가입하고 로그인합니다.
2. 대시보드에서 **Create cronjob**을 누릅니다.
3. URL에 다음 주소를 입력합니다.

   `https://kdtaihackathon-web.vercel.app/api/cron/scan`

4. 실행 간격을 **Every 1 minute**으로 지정합니다.
5. **Advanced → Headers**에 다음 값을 추가합니다.

   - 이름: `Authorization`
   - 값: `Bearer <CRON_SECRET>`

6. 저장하고 첫 실행 결과가 HTTP 200인지 확인합니다.

`<CRON_SECRET>`에는 Vercel 프로젝트 환경변수 `CRON_SECRET`과 같은 값을 넣습니다. 이 값은 문서나 저장소에 기록하지 않습니다. 동일한 cron 요청이 30초 이내에 중복되면 서버가 안전하게 건너뜁니다.

기존 GitHub Actions 또는 Vercel의 15분 이상 간격 스케줄은 외부 스케줄러 장애 시 보조 수단으로 남겨 둡니다.

## 무료 LLM 키 발급

키를 발급한 뒤 Vercel 프로젝트의 **Settings → Environment Variables**에 추가하고 재배포합니다.

### Groq

1. Groq Console의 **API Keys**에서 키를 만듭니다.
2. `GROQ_API_KEY`에 저장합니다.
3. 모델을 바꾸려면 `GROQ_MODEL`을 설정합니다. 기본값은 `llama-3.1-8b-instant`입니다.

### OpenRouter

1. OpenRouter의 **Keys** 화면에서 키를 만듭니다.
2. `OPENROUTER_API_KEY`에 저장합니다.
3. 모델을 바꾸려면 `OPENROUTER_MODEL`을 설정합니다. 기본값은 `meta-llama/llama-3.3-70b-instruct:free`입니다.

무료 모델은 제공 상황에 따라 중단되거나 제한될 수 있으며, 오류가 나면 다음 공급자로 자동 전환됩니다.

### Cloudflare Workers AI

1. Cloudflare Dashboard에서 계정 ID를 확인해 `CF_ACCOUNT_ID`에 저장합니다.
2. **My Profile → API Tokens → Create Token**에서 Workers AI 호출 권한이 있는 토큰을 만들고 `CF_API_TOKEN`에 저장합니다.
3. 모델을 바꾸려면 `CF_MODEL`을 설정합니다. 기본값은 `@cf/meta/llama-3.1-8b-instruct`입니다.

공급자 우선순위는 Groq → OpenRouter → Cloudflare Workers AI → Gemini → Anthropic입니다. `/api/ai-status`에서는 공급자별 성공·실패 횟수와 쿨다운 잔여 시간만 확인할 수 있으며 키 값은 반환하지 않습니다.
