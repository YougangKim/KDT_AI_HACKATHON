## 1. 조사 방법

- 대상: 한국 거주 만 19~34세 청년. 조사마다 모집단이 조금씩 다르다(국토부는 가구주 19~34세 청년가구, 경총은 20~34세 미취업 구직자 등).
- 자료: 정부·공공기관 통계, 연구기관·채용·알바 플랫폼 설문, 언론, 커뮤니티 게시글(링커리어, 디시 취업갤, 더쿠, 알바몬 커뮤니티).
- 커뮤니티 글은 빈도 수치로 환산하지 않고 **정성 근거**로만 썼다. 에브리타임·블라인드는 로그인 제한, 인스티즈는 robots 제한으로 원문 검증 불가.
- 점수 기준
  - 빈도(1~5): 5점은 관련 응답 60% 이상, 4점 40~59%, 3점 20~39%, 2점 10~19% 또는 보편성 입증이 어려운 정성 근거, 1점은 희소 사례.
  - 심각성(1~5): 금전·시간·건강·안전 손실 종합.
  - 해결난이도(1~5): "개인 개발자가 AI 에이전트 웹서비스 MVP를 3일 안에 만들어 문제를 실제로 줄일 수 있는가". 1점은 정보 조합·계산으로 상당 부분 해결, 5점은 서비스가 바꿀 수 없는 구조 문제.
  - **종합점수 = 0.5×빈도 + 0.3×심각성 + 0.2×(6−해결난이도)**

## 2. 분야별 핵심 근거

### 주거
- 청년가구 80.6%가 임차, 청년 임차가구 69.3%가 임대료·대출 상환 부담 (국토부 2025). RIR 17.4%로 전년 16.0%보다 상승.
- 20~30대 1,547명 중 40.2%가 주거비를 가장 부담스러운 지출로 꼽음 (다방 2024).
- 독립 청년의 주거 선택 기준 1위 통근·통학 39.2%, 2위 주거비 29.7% (국무조정실 2024). **실제 의사결정은 가격과 이동시간의 최적화 문제.**
- 서울 대학가·오피스텔 평균 월세 57.4만 원에 관리비 7.2만 원, 월세 50만 원에 관리비 22만 원 사례도 있음 (한국일보 2024). 더쿠에 "관리비 11만 원이 적정한가" 류 글 반복.
- 전세사기 피해자 중 20대 25.8%, 30대 48.4% (국토연구원 2024.10까지). 피해자 중 비중이지 청년 전체 피해율이 아니라서 심각성 근거로만 사용.

### 교통
- 20~30대 직장인 1,793명 중 84%가 대중교통 이용 시 스트레스 (캐치 2024).
- 평균 출근 48.4분, 경기 거주자 58.2분, "출근길에 사람이 너무 많다" 41.2% (잡코리아 직장인 1,010명).
- 평균 출퇴근 왕복 73.9분, 수도권 82분 (통계청 2024 통근 이동 실험통계).
- 버스 최대 불편은 배차간격 30.6% (인천 2026, 533명). 울산 노선개편 의견 8,432건 중 51.1%가 배차 단축 요구. 청년 한정 모집단 아님.
- 서울 청년 약 2,600명 중 야간 귀가·대중교통·택시 이용 시 불안: 여성 59.1%, 남성 26.3% (2026).

### 정규직 구직
- 미취업 20~34세 1,000명 중 80.7%가 최대 애로로 "업무 경험·경력개발 기회 부족", 일자리 정보 부족 45.3%, 자격증 30.8% (경총 2025).
- 취준생 1,202명 중 83%가 이력서·자소서에 가장 많은 시간을 투자, 35.3%가 서류전형을 가장 부담. 이유는 경쟁력 약하다고 느낌 41.2%, 혼자 준비해 방향 확신 없음 35.1%, **객관적 피드백을 못 받음 33.1%** (사람인 2026).
- 취준생 552명 중 75% 이상이 3개월 이상 취준, "서류에서 계속 탈락할 때"가 핵심 스트레스 (잡코리아 2025).
- 결과 통보 부재: 서울신문 2026 취재, 링커리어·디시 "서류 읽씹", "30군데 넘게 지원했지만 연락 없음" (정성 근거).
- 취업준비비: 월 28만 원, 43%가 전년보다 증가 (캐치 2025). 19~34세 1,000명 월 58만 원, 69.3%가 부담 (한경협 2026). 졸업 취준생 71.1%가 경제적 어려움 (잡코리아 2025).
- 취준 청년 42.3%가 AI 도구 사용 경험, 그중 77.2%가 이력서·자소서에 사용.

### 아르바이트
- 20대 68.5%, 30대 70.1%가 알바 구하기 어렵다. 56.7%가 "일자리는 많지만 나에게 맞는 알바 찾기가 어렵다" (알바몬 2024, 1,840명). 대학생은 근무지 위치 64.1%, 근무시간대 47.2%를 중시 (알바몬 2026).
- 알바몬 커뮤니티: "50개 넘게 지원, 연락 없음", "열람 후 연락 없는데 같은 공고가 다시 올라옴" (정성 근거).
- 알바 경험자 2,457명 중 48.0%가 임금 문제 경험. 주휴 등 수당 지연·미지급 37.3%, 임금 지연·미지급 32.8%, 약속보다 적은 임금 23.9%, 최저임금 위반 22.6% (알바천국 2025).
- 알바생 2,180명 중 30.5%가 고용주와 갈등, 근로계약서 미작성 24.2% (알바천국 2024).
- 알바 중 고객 갑질 직접 경험 30.3%, 20대 46.8% (직장갑질119 2026).

## 4. 소프트웨어 해결방안 (GPT 제안 + 수상 관문 판정)

GPT 결론: "문제를 없애는 앱"보다 **이미 있는 데이터와 사용자 상황을 결합해 결정을 대신 계산해 주는 에이전트**가 3일 MVP로 현실적이다.

판정 기준(프로젝트 규칙): 실사용 가능, 문제 해결, 개인 발급 API로 마감 전 완성 가능, 입상 가능.

### A. 취준 지원서 코파일럿 (지원 의사결정 에이전트) — 구직 1위(4.50), 11위(3.70) 해결
- AI가 하는 일: 공고(JD) 파싱 → NCS·직무기술서와 매핑 → 내 이력서에서 근거 문장 추출 → "필수 역량 8개 중 근거 없는 3개", 탈락 위험 문장, 지원하지 말아야 할 이유, 예상 면접질문 생성.
- 데이터(GPT 제안): 고용24 채용정보 API + 한국고용정보원 직무데이터/NCS API (인증키 필요, XML).
- 기존 서비스: 사람인·잡코리아·생성형 AI가 자소서 작성·공고 추천, 고용부 잡케어+. 빈틈은 문장 생성이 아니라 **지원 여부 판단과 역량 근거 매핑**.
- 리스크: 합격확률을 근거 없이 수치화하지 않을 것.
- **판정: 통과 (권장).** 고용24 대신 이미 확보 가능한 **잡알리오(자동승인)** 공공기관 공고로 대체하면 데이터 리스크가 없다. 현재 확정 방향(F안)과 그대로 이어진다. NCS API 개인 발급 조건은 확인 필요.

### B. 공고 + 출퇴근 현실성 평가 에이전트 — 주거 7위, 교통 15위(3.40) 해결
- AI가 하는 일: 공고 20개를 불러와 집 주소 기준 통근시간·환승횟수·막차 위험·월 교통비를 계산해 "지원 우선순위" 생성.
- 데이터(GPT 제안): 고용24 채용정보 OpenAPI + 카카오맵 대중교통 경로 API(일 1,000건 무료라고 GPT 기재).
- **판정: A의 확장 기능으로 통과.** 고용24는 개인키 반려 사례가 있어 잡알리오로 대체. 대중교통 경로 API의 개인 발급·무료 한도는 원문 근거가 약해 **직접 확인 필요**. A에 "통근시간" 필터로 붙이는 게 맞다.

### C. 주거 총비용·위험 점검 에이전트 — 주거 1위(4.50), 5위(4.10), 7위(4.00), 8위(3.90) 해결
- AI가 하는 일: 주소·보증금·월세 입력 → 주변 실거래 비교 → 관리비·대출이자·교통비까지 월 총비용 → 건축물 용도·연식 위험 체크리스트.
- 데이터: 국토부 아파트·연립다세대·오피스텔·단독다가구 전월세 실거래가 OpenAPI(개발계정 일 10,000건, 자동승인), 건축HUB 건축물대장 API(자동승인, 월간 갱신). 동·호 등 일부 정보는 미제공.
- 기존 서비스: 직방·다방·네이버부동산은 매물·가격·지도는 강함. 빈틈은 "내 소득에서 총비용 얼마인가, 비슷한 실거래 대비 보증금이 높은가"를 한 번에 판단해 주는 것.
- 리스크: '안전 보증'처럼 표현하면 안 되고 위험 신호 안내로 한정.
- **판정: 통과 (강한 대안).** 데이터가 모두 자동승인이라 가장 안전하다. 다만 지금 확정된 F안(구직)에서 방향을 바꾸는 것이라 사용자 선택이 필요하다.

### D. 알바 권리·급여 검산 에이전트 — 알바 4위(4.30), 17위(3.30) 해결
- AI가 하는 일: 근무기록 입력 → 주휴·연장 포함 예상 급여 자동계산 → 차액 표시 → 계약서·계좌내역 증빙 체크리스트 → 1350 신고 절차 안내.
- 데이터: 고용부 최저임금·주휴 규정(공식 자료), 고용24 '임금체불 명단공개 사업주 여부' API(2026.1 신규, 인증키 필요).
- **판정: 조건부 통과.** 계산은 데이터 없이 가능하지만 심사위원에게 "급여 계산기"로 보일 위험이 있다. 체불 사업주 조회는 고용24 키 문제로 불확실. 법률 대리처럼 표현하면 안 된다.

### E. 알바 맞춤검색 에이전트 — 알바 3위(4.40)
- 민간 알바 플랫폼은 공개 API가 없고 크롤링은 약관 위반 위험. 고용24 시간제 정보는 키 문제.
- **판정: 반려.** 대회 규정상 약관 위반 데이터 사용은 실격 사유이고, 합법 데이터 확보가 안 된다.

## 5. 결론

- 빈도·심각성 기준 1위는 **구직 서류 반복 탈락·피드백 부재(4.50)**와 **주거 총비용 판단(4.50)**이 공동 1위다.
- 현재 확정 방향(F안, 잡알리오)을 유지한다면 **A안(지원 의사결정 코파일럿) + B안(통근시간)**을 결합하는 것이 순위 1위 고민을 정면으로 다루고 데이터 리스크도 없다.
- 데이터가 가장 안정적인 대안은 **C안(주거 총비용·위험 점검)**이다.

## 6. 수상작 패턴으로 다시 본 주제 (2026-11-21 추가)

사용자가 예로 든 수상작 패턴: 좁은 타깃 + **AI가 비전문가의 의도를 전문가가 바로 작업할 수 있는 산출물(시안·발주서)로 변환** + 그 산출물이 **소상공인 일감**으로 이어지는 양면 구조.

### 추천: 동네 일감 브리프 (소상공인 소일감 → 청년 일경험)
- 근거 고민: 경험 부족 80.7%(4.10), 서류 반복 탈락·근거 부족(4.50), 취준 비용(3.80)
- 사장 쪽: "인스타 홍보 좀 해줘" 같은 한 줄 요청과 가게 사진·메뉴를 넣으면 AI가 **1~3일짜리 과업지시서**(산출물 예시, 완료 기준, 예상 시간, 최저임금 이상 보수)로 바꿈
- 청년 쪽: 과업 수행 → 사장 확인 → AI가 산출물과 사장 평가를 근거로 **이력서용 경험기술서**(NCS 직무역량에 맞춘 문장)를 생성
- 기존 서비스 빈틈: 크몽·숨고는 숙련 프리랜서 대상, 고용부 일경험은 기업 단위 대규모. 동네 가게의 작은 일을 신입이 할 수 있게 쪼개 주는 곳이 없음
- 데이터: 소상공인 상가(상권)정보 API(data.go.kr), NCS 직무 정보. 데모는 시드 데이터로 충분
- 리스크: 무급 노동처럼 보이면 안 됨 → 보수 하한 강제

### 대안: 사장·알바 공용 근로계약·급여명세 작성기
- 근거 고민: 임금·수당 문제 48%(4.30), 근로계약서 미작성 24.2%
- 사장이 말로 근무 조건을 넣으면 AI가 표준근로계약서 + 주휴 포함 급여명세서 작성(계산은 코드), 알바생은 같은 문서로 확인
- 약점: 알바몬 등에 전자근로계약 기능이 이미 있어 차별화가 약함

### 맞지 않는 분야
- 주거·교통: 공급자 쪽(중개사·운송)이 소상공인 일감 구조로 잘 이어지지 않고, AI 산출물이 계산 결과에 그침
