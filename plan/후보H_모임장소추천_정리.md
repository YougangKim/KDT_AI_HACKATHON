# 후보 H: 여럿이 모일 "갈 만한" 장소·코스 추천 에이전트 (정리본, 평가 전)

## 사용자 문제 (인터뷰 원문 요지)
- 경기 북부 거주. 철도가 서울 방향 위주라 경기권끼리 이동이 불편하고, 즐길 거리는 서울에 몰려 있어 친구 만나기가 힘듦.
- 사람들은 거리 중간점이 아니라 **할 거리가 모인 곳(핫플레이스)** 으로 모인다. 예: 라면을 좋아하면 라면집이 많은 합정으로.
- 기존 "중간지점 찾기"는 평균 거리로 아무 동네나 찍어 줘서 "거기 가면 뭐 하냐"가 됨.

## 아이디어
여러 명의 **출발지 + 각자 취향(음식·활동)** 을 받아, (1) 공통 관심사를 만족하는 거리(상권)를 고르고 (2) 각자 대중교통 시간·요금이 **고르게** 나오는 곳을 우선해 (3) 밥 → 커피 → 영화 같은 **코스**로 묶어 추천. 결과를 단톡방 공유 카드로 만든다.

## 흐름
1. 방장이 링크 생성 → 친구들이 각자 출발역·좋아하는 것(자유 문장 "라면 좋아함, 사진 찍기") 입력
2. LLM이 취향 문장을 카테고리·키워드로 구조화, 공통분모 도출
3. 후보 상권 10곳 × 인원 N명 대중교통 소요시간·요금 행렬 계산(코드)
4. 점수 = 취향 일치(가게 수·다양성) + 공평성(시간·요금 편차 작게) + 총 이동시간 → 상위 3곳
5. 각 상권에서 코스 3단계 생성, "왜 여기인지" 설명, 공유 카드 이미지
