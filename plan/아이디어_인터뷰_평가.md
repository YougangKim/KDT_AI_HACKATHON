## 3. 추천안 G: 청년 혜택·공고 지원 준비 에이전트

- 한 줄: 공고는 "찾는 것"보다 **"나 되는지 판단하고 서류 준비해서 마감 전에 내는 것"**에서 막힌다. AI가 공고를 읽고 → 내 조건으로 자격을 판정하고(근거 문장 표시) → 필요한 서류·발급처·순서를 마감일에서 거꾸로 짠 준비 계획으로 바꿔 준다.
- 사용자 고통과의 연결: "준비 과정이 복잡" → 준비 계획 / "상관없는 게 많음" → 자격 판정으로 걸러냄 / "언제 뜰지 모름" → 조건 저장 후 새 공고만 표시(확장)
- 기존 서비스 빈틈: 보조금24·온통청년·카카오 혜택 알림은 "목록 추천"에서 끝남. 자격요건 문장 해석과 서류 준비 순서는 사용자 몫으로 남음
- AI 역할(25점): 비정형 자격요건 문장 → 조건 구조화, 사용자 상황 대화로 수집, 서류 준비 계획 생성. 판정 로직은 코드, 애매한 조건은 "확인 필요"로 표시(오류 대응 5점)
- 데이터(개인·자동승인 우선, 발급 첫 단계에서 실제 호출로 확인): 행안부 공공서비스(혜택) 정보 API(지원대상·선정기준·구비서류·신청기한 포함, 자동승인으로 알고 있음 → **확인 필요**), 국민내일배움카드·KDT 훈련과정 API(자동승인), Q-Net 시험일정(자동승인), 잡알리오(공개)
- 리스크: 경쟁 서비스가 많아 차별성은 "준비 계획"을 시연에서 확실히 보여 줘야 함. 자격 판정 오류 시 피해 → "최종 확인은 공고처" 고지와 근거 문장 링크 필수
